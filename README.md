# Algoritmi e strutture dati

Raccolta di alcune strutture dati realizzate in C++ durante il corso di
Algoritmi e Strutture Dati.

## Struttura

- **Liste**: liste concatenate, liste basate su vettore, liste ordinate e polinomi
- **Pile**: pila concatenata, pila basata su vettore e pile multiple
- **Code**: code concatenate e basate su vettore
- **CodeP**: coda con priorità e heapsort
- **Dizionari**: dizionario e tabella hash
- **Grafi**: rappresentazione con liste di adiacenza e matrice di adiacenza
- **AlberiBin**: alberi binari con rappresentazione tramite puntatori e vettore
- **AlberiN**: alberi n-ari con rappresentazione tramite puntatori e vettore

Le varie strutture sono state realizzate durante il corso per lo studio, le
esercitazioni e la preparazione dell'esame.
